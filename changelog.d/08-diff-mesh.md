### Added
- New MCP tool `diff_mesh` (the seventh): a contract-level diff of the working tree (uncommitted edits and untracked files included) against a Git base, per configured root and per repository. It lists, per changed file, declarations added, removed or with a changed signature, gRPC services and RPCs, HTTP routes, topics produced and consumed, imports and RPC calls (body-only edits are counted, never listed); then, from the live graph, the callers and dependents of every removed or changed symbol and RPC (`path:line`, `exact`/`heuristic`/`ambiguous`), and the `.proto` wire-format check of every changed `.proto` against the same base. Arguments: `base` (same validation and default as `analyze_grpc`) and `scope` (jailed like `smart_search`). Bounded: 2,000 files per call with a truncation note, a 20 s budget per call (files not reached are named as not analysed), the 500 ms query parse budget (never indexing's 2 s), 4 MB per path listing, 32 MB of base contents read through one `git cat-file --batch` per repository, both versions through the indexer's guards, output budgeted inside the tool under the 48 KB cap (summary, then wire results, never dropped, then impact rows, then per-file sections, each cut section saying how many were left out). A root outside Git, an unknown `base` (with a shallow-clone hint) and a malformed `base` (`-32602`) are explicit errors.
- `ContractGraph::recorded_rpc_callers`: the call sites recorded for `Service.Method`, resolved or not (a caller of a removed RPC has no edge left), including a call naming the service with its proto package and service-level clients (`may call`, heuristic).
- `PolyglotIndexer::extract_with_budget`: extraction with an explicit tree-sitter parse budget; `extract_with_config` (indexing) keeps `INDEX_PARSE_TIMEOUT_MICROS`.
- `AstGuard::check_content`: the lexical guard for contents that are not on disk.
- `GitRunner::run_with_input`: stdin for `git`, under the same timeout and output bound.
