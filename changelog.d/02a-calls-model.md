- Add the calls layer (9.0): `NodeKind::Callable` and `EdgeKind::Calls`, derived after every reconcile from new per-file call facts (`FileIndex::calls`: callables, call sites, injections, imports, type heritage). Only callables on a call path from an entry (consumer, HTTP route, gRPC handler) to a producer are materialized; `graph --format json` and the fingerprint include them, no tool reads them yet.
- TypeScript / NestJS / Angular call extraction and resolution: `this.m()`, `this.dep.m()` through constructor parameter properties, typed fields and `inject(T)`, imported and same-module functions, re-exports, interfaces and abstract classes through their implementations (several candidates: `ambiguous`), workspace package imports matched by package name (`heuristic`).
- TypeScript call-site producers (`client.emit`, `producer.send`, `redis.publish`, ...) are registered on the call itself, at the line of the call, instead of the enclosing method or class (8.0.1 defects N2 and N9). `analyze_impact` shows the call line and names the publishing declaration in the `Via` column. Call-site consumers stay on their handler.
- Parse cache `SCHEMA_VERSION` 12 -> 13: existing caches are re-parsed once.
- `IndexHealth::files_call_facts_capped` and `IndexHealth::call_sites_skipped` count the files whose call facts hit a per-file cap and the call sites past the whole-graph cap; `doctor` and the index summary name them (warning).
- `analyze_impact`: a producer row whose node is a call site (named after its topic) names the declaration that publishes in the `Via` column, in every language (e.g. polyglot-shop `BillingSaga.java:16`, `Via` `BillingSaga`, was `-`).
- Memory: the raw call facts of every non-test TS / JS file stay in memory (pruning is at derive time, not fold time); test files carry none. Peak memory footprint, cold cache, `graph --format fingerprint`, median: Volontariapp 159.5 -> 167.9 MB (+5 %, run-to-run spread about 15 MB), vscode 3,784 -> 3,853 MB (+1.8 %; `--format json`: 1,450 -> 1,532 MB cold, +5.6 %, one run each). The calls index is skipped when no file holds both an entry and a producer.
