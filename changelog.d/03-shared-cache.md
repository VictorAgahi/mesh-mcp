### Breaking
- Persistent parse cache location: inside a Git repository it now lives at `~/.cache/mesh-mcp/workspaces/<cache_family_id>/index-cache.db`, one database shared by every worktree and every config file of the repository (marked by a `family_common_dir` file instead of `workspace_path`). Records are shared within one binary version: the version is part of every key, so an upgrade re-parses once and the previous version's rows age out through LRU eviction. Outside Git the per-workspace directory is unchanged. The first boot after upgrading parses everything once.
- Cache schema 12 (was 11): keys hold the binary version and the file's root-relative path (`/`-separated) instead of its absolute path, plus the path-derived extraction context (parent directory name of an `index.*` file, path substring tests); a record that uses the package inferred from directories is keyed by that package too. Records store root-relative node paths, re-anchored on the reading checkout. Older databases are dropped and recreated on open. `PersistentIndexCache::key_for` takes the relative path as `&str`.

### Changed
- A second worktree of the same commit, or a checkout moved elsewhere, boots on cache hits and produces the same snapshot fingerprint. A file whose facts depend on the checkout's own directory (a package named after it when no manifest declares one) gets a different key and is parsed, never served another checkout's answer; a file that declares its package keeps sharing its record.
- `tsconfig` / `package.json` alias targets enter a file's cache key relative to its workspace root.
- The inferred package is now part of the key of the records that use it, so renaming a manifest's `name` re-extracts the files it governs instead of serving the old package from the cache.
- `doctor --fix` also removes a pre-8.0 per-worktree cache directory of any worktree of the current repository that still exists, and never reports the shared directory as orphaned. A 7.x directory whose worktree was deleted is not recognised and stays (it is safe to delete by hand).
