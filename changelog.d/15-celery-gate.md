- Python Celery detection is gated on the file's parsed imports (9.0 T15). A decorator is a Celery consumer, and `.delay()` / `.apply_async()` a producer, only when the file imports `celery` (`import celery`, `from celery import ...`, `from celery.x import ...`), or the receiver is imported from a module whose path holds `celery` or `tasks` (`from proj.celery import app` then `@app.task` keeps working), or the bare `@shared_task` / `@task` is imported from a celery module and not redefined in the file. A Locust `@task`, a local decorator named `task` and a `task` of another library are no consumers, no queue nodes and no events.
