- BullMQ / Bull queues named by an enum member resolve to the member's string value (9.0 T14, tag `enum_topic`). `@Processor(JobQueue.EMAIL)`, `@InjectQueue(JobQueue.EMAIL)`, `new Queue(JobQueue.EMAIL)`, `new Worker(JobQueue.EMAIL, ...)` and the `bull` constructor are resolved against the workspace's string constants when the file is folded: the producer and the consumer meet on `email-jobs`. The declaration is chosen by the site's own imports (relative path, alias, namespace import, else the importer's repository), never by the bare enum name; two candidates that disagree resolve to neither (qualified key `jobqueue.email`, `heuristic`, counted in `IndexHealth::const_members_conflicting`, `doctor` warns). A member no indexed file declares keeps the QUALIFIED member key (`externalqueue.billing`, `heuristic`), not the bare member shared by every enum. Events, streams and Kafka topics given as enum members keep the member key: a codebase that names a stream and its event type alike links them by it. A custom-pattern capture of a member joins a queue by value only when its file's imports bind it to a declaration a queue site names a queue by.
- Constants of test files are never recorded; a member named like a credential, and a value that is a token, a URL, `Bearer_...`, password-shaped or random-looking, are never a topic name. `analyze_impact` / `trace_flow` accept the member as written, its value or the qualified key.
- Bounded and counted: 4,000 string constants per file (`IndexHealth::files_const_capped`), `doctor` warns on a cap and on members declared with different values. 2 MB stack probe with a 3,000-member enum and an enum alias cycle. `BullModule.registerQueue` is not a producer. Not read: `static` class fields, lowercase object keys, template literals, `FlowProducer`, an aliased `bee-queue` constructor. See `docs/parser-support.md` section 3.8.
- Parse cache `SCHEMA_VERSION` 20 -> 21 (after T8a's 20) (a TS / JS record holds `FileIndex::member_imports`, `member_sites`, `const_capped`); existing caches are re-parsed once. New golden corpus `examples/eda/bullmq-enum-queues`, new tag `enum_topic`.
