- BullMQ / Bull queues named by an enum member resolve to the member's string value (9.0 T14, tag `enum_topic`). `@Processor(JobQueue.EMAIL)`, `@InjectQueue(JobQueue.EMAIL)`, `new Queue(JobQueue.EMAIL)`, `new Worker(JobQueue.EMAIL, ...)` and the `bull` constructor are resolved against the workspace's string constants when the file is folded: the producer and the consumer meet on `email-jobs`. The declaration is chosen by the site's own imports (a relative path, alias or namespace import to the declaring file; a package import only to the declarations of the package it names, by package.json name; never to a homonymous enum of the importer's repository), never by the bare enum name; two candidates that disagree resolve to neither (qualified key `jobqueue.email`, `heuristic`, counted in `IndexHealth::const_members_conflicting`, `doctor` warns). A member no indexed file declares keeps the QUALIFIED member key (`externalqueue.billing`, `heuristic`), not the bare member shared by every enum. Events, streams and Kafka topics given as enum members keep the member key: a codebase that names a stream and its event type alike links them by it. A custom-pattern capture of a member joins a queue by value only when its file's imports bind it to a declaration a queue site names a queue by.
- Constants of test files and of build output (`dist/`, `out/`, ...) are never recorded. A member named like a credential (whole word `KEY`, `PASSWORD`, ...), and a value that is a token, a URL, `Bearer_...`, a known weak password or random-looking, are refused where the constants are extracted: they never enter the graph or the parse cache (`password-reset-jobs`, `private-events`, `orders2024` are names). `analyze_impact` / `trace_flow` accept the member as written, its value or the qualified key.
- Bounded and counted: 4,000 string constants per file (`IndexHealth::files_const_capped`), 4,000 string constants and 512 enum imports per file; `doctor` warns on a cap and on members a queue site could not choose between. 2 MB stack probe with a 3,000-member enum and an enum alias cycle. `BullModule.registerQueue` is not a producer. Not read (silently): camelCase members, `const q = JobQueue`, dynamic `import()` / `require`, `static` class fields, template literals, `FlowProducer`, an aliased `bee-queue` constructor; qualified-key fallbacks for a default import, a renamed re-export, a namespace-nested enum and a `.d.ts`. See `docs/parser-support.md` section 3.8.
